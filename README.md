# Personal website redirect

GitHub Pages publishes this repository at https://lbg21.github.io/.
The root page immediately redirects to https://lbg21.github.io/LBG21/.
JavaScript preserves query parameters and fragment identifiers. A meta refresh
and a visible link provide fallbacks when JavaScript is unavailable.

Publishing source: the root directory of the `main` branch.

The personal website itself is maintained in [LBG21/LBG21](https://github.com/LBG21/LBG21).
